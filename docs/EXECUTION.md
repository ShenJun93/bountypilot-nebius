## Product thesis

BountyPilot is not a one-turn Q&A wrapper. It turns opportunity hunting into a stateful workflow:

1. analyze a bounty/hackathon;
2. save it to a persistent queue;
3. compare several opportunities;
4. preserve blockers and unknowns;
5. generate a concrete submission plan;
6. update execution state;
7. return the next best action in later sessions.

## MCP implementation

Endpoint:
`/mcp`

Transport:
Streamable HTTP through the official Model Context Protocol TypeScript SDK.

Registered tools:
1. `analyze_opportunity`
2. `save_opportunity`
3. `get_opportunity_queue`
4. `compare_opportunities`
5. `build_submission_plan`
6. `set_opportunity_status`
7. `next_best_action`

The web simulator uses `@modelcontextprotocol/client` over the SDK's `InMemoryTransport`; it does not bypass the MCP tool layer and call analyzer/store functions directly. The separately exposed `/mcp` route serves the same seven tools over Streamable HTTP for external clients.
